## 1. 先講最重要的：`WalletModel` 不變

範圍二**不會**改 `WalletModel`。它仍然是**內部帳本（IOU）**——記著「交易所欠這個用戶多少幣」，
`available` / `frozen` 的語意、不變量、鎖策略全部照舊。

真正的幣不在 `WalletModel` 裡，而是集中在**交易所自己的鏈上錢包**（熱錢包/冷錢包）。
所以範圍二在 `member` 要新增的不是「錢包」，而是**充值地址管理**——一個全新的、屬於鏈上世界的概念。

> 別把 `WalletModel`（內部帳本）和「鏈上錢包」（私鑰的集合）搞混，這是最常見的觀念混淆。
> 也別把 `UserProfileModel.address`（**住址**）和鏈上地址搞混。

## 2. 充值地址（`DepositAddressModel`）

### 2.1 為什麼每個用戶要有專屬地址

**鏈上轉帳不會附帶「我是誰」這種資訊。** 交易所收到一筆入金時，鏈上只告訴你
「有 X 顆幣進了地址 A」——它不知道這是誰付的、要記到誰頭上。

所以交易所只能**用地址本身當身分識別**：事先替每個用戶、每個幣別配一個**專屬**充值地址，
記著「地址 A 是配給用戶 123 的」。監聽服務看到錢進了 A，就知道要加給用戶 123。

### 2.2 欄位

| 欄位 | 說明 |
|---|---|
| `user` | FK → User |
| `asset_type` | FK → CurrencyModel（已含 `chain`，見 `01-2` §2） |
| `address` | CharField(100)，**unique**。鏈上地址 |
| `derivation_index` | 這個地址在 HD 派生路徑上的序號（見下） |
| `created_at` | 時間 |

約束：`unique_together = (user, asset_type)` — 每人每幣一個地址；`address` 全域唯一。

> **EVM 系可共用**：以太坊、Polygon、BSC、Arbitrum… 地址格式相同，同一個地址在這些鏈上都能收。
> 但**餘額各自獨立**。設計時可考慮「同一用戶在所有 EVM 鏈共用一個地址」，比特幣則另一套。

### 2.3 HD Wallet 派生：不要管理十萬把私鑰

若每個用戶每個幣都獨立產生一把私鑰，十萬個用戶就是十萬把私鑰要保管——災難。

正解是 **HD Wallet（分層確定性錢包，BIP32/BIP44）**：從**一組主種子（seed）**，
依一條**派生路徑**（例如 `m/44'/60'/0'/0/{index}`）可以算出**無限多組**私鑰/地址，
而且只要保住那一組 seed，任何時候都能重新算出所有地址的私鑰。

所以資料庫只需要存 `derivation_index`（第幾號），**私鑰完全不進資料庫**。

> **私鑰保管鐵則**：主種子走環境變數 / 金鑰管理服務（KMS），**絕不可 commit 進 git、絕不可寫死在程式裡**。
> 種子外洩 = 所有用戶的充值地址都被掌控。

### 2.4 API

- `GET /api/deposit/address/?asset_type_id=` — 取得（或首次派生）我的充值地址。
  `IsAuthenticated`，只能拿自己的。
  **這是範圍二唯一新增的用戶端入金 API——它只給地址，不動任何餘額。**

> 呼應 `06-1` §2.2：入帳永遠是**系統觸發**（監聽服務），不存在「用戶呼叫 API 說幫我入金」。
> 用戶端能做的只有兩件事：**要一個地址**，然後**自己去鏈上轉帳**。

## 3. 交易所自己的錢包（熱 / 冷）

這不是用戶的錢包，是交易所的資金庫。

- **熱錢包**：私鑰連網、能自動簽名，用於出金。只放一小部分資金（被駭風險）。
- **冷錢包**：私鑰離線保管，放大部分資金，動用需人工。
- **歸集（sweeping）**：用戶充值地址收到的幣，會定期集中搬到熱/冷錢包統一管理
  （否則資金散在成千上萬個地址上，出金時湊不出來）。歸集本身也是鏈上轉帳，要付 gas。

詳見 `06-2` §4。

## 4. 常見坑

- **把 `WalletModel` 當成鏈上錢包** → 觀念根本錯誤。它是帳本，不是私鑰的集合。
- **私鑰進 DB 或 git** → 等同公開金庫。只存 `derivation_index`。
- **地址重複配給兩個用戶** → 入金會記到錯的人頭上。`address` 必須 unique。
- **忘了歸集** → 資金散落在各充值地址，熱錢包湊不出出金要的量。
- **忽略「送錯鏈」** → 用戶把 Tron USDT 轉到 EVM 地址，資產永久遺失。UI 一定要逼用戶選網路並警告。
